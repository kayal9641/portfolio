# JANANI.EXE — The Digital Universe
Run: `npm install` then `npm run dev` (open the printed URL). Check: `npm run build`.
Edit everything in `src/config.ts`. Empty values are hidden automatically.
- Resume: set `resumeUrl`. Upload to Google Drive, Share > General access > "Anyone with the link — Viewer", copy link. Empty = button hidden.
- Projects: fill `problem`, `objective`, `methodology`, `technologies`, `contribution`, `status`, `results`, and each `extra` value. Add `link` only for a real URL.
- Deploy: Vercel (import the repo, framework Vite, no settings needed) or GitHub Pages (upload `dist/`; `base: "./"` is already set).
